# Resident Evil Blog

Μια responsive εφαρμογή όπου παρουσιάζεται μία σειρά παιχνιδιών με μία σύντομη περιγραφή του κάθε παιχνιδιού.

# Περιγραφή

Ο χρήστης μπορεί να δει μία σύντομη περιγραφή της σειράς παιχνιδιών Resident Evil αλλά και σύντομες περιγραφές για κάθε παιχνίδι ξεχωριστά συνοδευόμενα από μία εικόνα και ένα link που μεταβαίνει στη wikipedia του παιχνιδιού που ενδιαφέρεται να μάθει περισσότερες πληροφορίες. Επίσης ο χρήστης έχει την δυνατότητα της γρήγορης μετάβασης στην περιγραφή του παιχνιδιού όπου τον ενδιαφέρει με την βοήθεια ενός navigation button.

# Βασικά Χαρακτηριστικά

- Navigation button
- Μεταβίβαση σε άλλη ιστοσελίδα μέσω link
- Responsive σχεδιασμός για διάφορα μεγέθη οθόνης
- Χρήση CSS για την διαχείριση χρωμάτων και styling

# Τεχνολογίες

- HTML5
- CSS
- JavaScript
